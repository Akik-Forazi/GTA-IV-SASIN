# GTA IV: SASIN

A fan-made single-player story campaign continuing Grand Theft Auto IV (Revenge Ending continuity: Roman survives, Kate dies).

## Project Overview
- **Protagonist:** Kim Haru / Ahsan ("SASIN")
- **Engine / Target:** GTA IV Complete Edition (Build 1.2.0.59)
- **Architecture:** C++ Native ASI / ScriptHook layer combined with Lua/JSON campaign definitions.

## Repository Structure
- `docs/` — Technical architecture, setup, compatibility, and safety documentation.
- `story/` — Narrative bibles, character profiles, and canon ledgers.
- `scripts/` — Mission scripts and event logic.
- `cinematics/` — Storyboards and shot lists for cutscenes and cinematic POCs.
- `assets/` — Reference materials and non-copyrighted design assets.
- `tests/` — Test harnesses and validation procedures.
- `tools/` — Development utilities and build scripts.
- `logs/` — Local execution logs (git-ignored except README).
