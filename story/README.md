# Story & Narrative Bible

Houses the narrative design, character arcs, conspiracy details, and act breakdowns for GTA IV: SASIN.

## Reading order
1. **canon-ledger.md** — source of truth (statuses + Decision Queue). Start here.
2. **writer_master_chronology.md** — WRITER EYES ONLY: the true chronology.
3. **characters/** — profiles with bounded knowledge per act.
4. **campaign-outline.md** — 17 missions / 5 acts.
5. **clue-schedule.md** — fair-play clue & reveal matrix.
6. **consequence-tracker.md** — branch ledger and prohibited branches.
7. **act1_mission*.md** — Act I scripts (4 missions).
8. **Readmap.md** — development stages and current position. **status.md** — live status log.

## Rules for contributors
- Never convert PROPOSED to CONFIRMED silently; canon changes require user approval recorded in the ledger.
- Writer-only material stays out of player-facing documents and mission dialogue.
- Every mission script carries Continuity Restrictions and Spoiler Check sections; keep them current in the same commit as the script.
